# Онлайн-бухгалтерия

## Для кого

Сервис онлайн-бухгалтерии рассчитан на ИП на упрощённой системе налогообложения (УСН «Доходы» 6% и УСН «Доходы минус расходы» 15%) без сотрудников и с сотрудниками.

## Что умеет

Сервис автоматически рассчитывает налоги и страховые взносы по операциям на расчётном счёте, напоминает о сроках уплаты, формирует и отправляет декларацию по УСН в налоговую.
Сервис не подходит для ООО и для ИП на общей системе налогообложения.

## Стоимость

Для ИП без сотрудников — 0 ₽ при обслуживании на тарифах «Деловой ритм» и «Бизнес-Макс», на тарифе «Первый шаг» — 490 ₽ в месяц.
Для ИП с сотрудниками — 1 990 ₽ в месяц на любом тарифе.

## Отчётность

Декларация по УСН формируется автоматически по итогам года. Её можно проверить и отправить в налоговую в один клик с помощью электронной подписи, которую выпускает банк бесплатно.
